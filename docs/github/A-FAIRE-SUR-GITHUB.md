qui porte **exactement ton nom d'utilisateur** : `adebayo-moutalabi/adebayo-moutalabi`. Il n'existe pas encore.

**À la main (1 minute) :**
1. github.com → bouton **+** en haut à droite → **New repository**.
2. Repository name : `adebayo-moutalabi` (GitHub affiche alors « ✨ You found a secret! »).
3. **Public**, cocher **Add a README file** → **Create repository**.

**Ensuite, par git :** le contenu est prêt dans [`README-profil.md`](README-profil.md).
Soit tu le copies-colles dans le README du nouveau dépôt (bouton ✏️ sur github.com),
soit tu me dis « le dépôt de profil existe » et je le pousse par une pull request.
